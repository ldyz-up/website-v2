# 配置询盘邮件（Cloudflare Worker + Resend）

网站页面仍由 GitHub Pages 托管；此 Worker 只接收询盘并请求 Resend 发邮件。不要把 Resend 密钥放进网站 JavaScript、HTML 或 GitHub。

## 需要准备

- 能登录 `ldyzgroup.com` DNS 管理后台的账号（建议用发送专用子域名 `notify.ldyzgroup.com`）。
- 一个 Resend 账号。
- 一个 Cloudflare 账号，并让 `ldyzgroup.com` 域名处于 Cloudflare 管理下，便于绑定 `forms.ldyzgroup.com`。

## 第一步：在 Resend 验证发件域名

1. 登录 Resend，打开 **Domains → Add Domain**。
2. 输入 `notify.ldyzgroup.com`。使用独立子域名，避免改动现有邮箱收件设置。
3. Resend 会显示需要添加的 DNS 记录。到 Cloudflare 的 `ldyzgroup.com` → **DNS → Records**，按 Resend 给出的名称和值逐条添加。不要删除或改动现有 MX 记录。
4. 回到 Resend 点 **Verify**，等状态显示验证成功。

## 第二步：创建邮件 API 密钥

1. 在 Resend 打开 **API Keys → Create API Key**。
2. 选择可发送邮件的权限，复制密钥并暂存到密码管理器。页面关闭后可能无法再次查看。
3. 免费方案当前额度请以 Resend 价格页显示为准；这套流程会把客户表单和附件交给 Resend 处理。

## 第三步：创建 Cloudflare Worker

1. 登录 Cloudflare，打开 **Workers & Pages → Create → Worker**，命名为 `ldyz-inquiry-mailer` 并创建。
2. 进入 Worker 的在线代码编辑器，打开本项目的 `cloudflare/inquiry-worker.js`，复制全部内容粘贴并保存。
3. 在 Worker 的 **Settings → Variables and Secrets** 添加以下三项。`RESEND_API_KEY` 一定选 **Secret**；另外两项使用普通变量即可：

   - `RESEND_API_KEY`：刚创建的 Resend API 密钥（Secret）
   - `INQUIRY_TO`：`sales@longdeyizhi.com`
   - `INQUIRY_FROM`：`LongDe Yizhi Website <inquiries@notify.ldyzgroup.com>`

4. 保存并 Deploy。
5. 在 Worker 的 **Settings → Domains & Routes → Add → Custom Domain** 添加 `forms.ldyzgroup.com`，等待 Cloudflare 显示启用。
6. 新询盘接口地址应为 `https://forms.ldyzgroup.com/submit`。

## 第四步：先验证邮件通道，再接入网站

先用浏览器打开 `https://forms.ldyzgroup.com/`。如果看到方法提示或非空白响应，代表 Worker 地址已启用；这不代表邮件已测试成功。然后由我把主页与活页夹页分别接入 `/submit`，再用测试表单验证正文、归属主题、配置摘要和附件。

目前网站表单尚未切换到此 Worker。确认 Resend 域名已验证、Worker 已部署后，再切换，避免配置期间询盘中断。

## 注意

- 发送成功响应表示 Resend 接受了邮件请求，不等于收件箱最终送达；上线前要检查 `sales@longdeyizhi.com` 实际收到测试邮件及附件。
- 当前 Worker 设为只接受 `https://ldyzgroup.com` 与 `https://www.ldyzgroup.com` 的网页来源；如果实际网址不同，需要调整允许名单。
- 当前 Worker 将附件总量限制为 15 MB，并拦截可执行文件。客户上传内容会通过 Resend 发送，不会保存到网站仓库。
- Cloudflare Worker 免费计划存在单次 CPU 时间限制；如果大附件编码触发限制，先降低网站附件总量，再考虑 Cloudflare Workers 付费额度。
- 邮件主题中的来源标签是营销归因信息，不是经过身份验证的客户身份凭证。
